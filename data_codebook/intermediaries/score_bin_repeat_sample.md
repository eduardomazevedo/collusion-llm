# score_bin_repeat_sample.csv

## Description
Fixed random sample for a post-analysis false-positive and threshold-stability diagnostic conducted in November 2026. The dataset contains 500 transcripts from each five-point original LLM score interval from [0, 5) through [70, 75). Eligible transcripts had exactly one existing `SimpleCapacityV8.1.1` query from `gpt-4o-mini`, were present in the local transcript-detail dataset, and had a valid original response. Each of the 7,500 transcripts received ten additional identical-prompt queries, producing eleven total trials. This sample is separate from the original LLM-flagged and validated samples.

## Generated by
Sample manifest: `src/query_submission/batch_queries/create_score_bin_repeat_sample.py`

Ten repetitions per transcript: `src/query_submission/batch_queries/score_bin_repeat_runner.py`

## Variables

### transcriptid
Unique Capital IQ transcript identifier. Integer.

### original_score
Score from the transcript's earliest `SimpleCapacityV8.1.1` query using `gpt-4o-mini`. Numeric value on the 0-100 scale.

### score_bin_lower
Inclusive lower bound of the transcript's five-point original-score interval. Integer.

### score_bin_upper
Exclusive upper bound of the transcript's five-point original-score interval. Integer.

### sample_rank
Deterministic rank from 1 through 500 within the sampled score interval after selected transcript IDs are sorted. Integer.

### existing_query_count
Number of matching `SimpleCapacityV8.1.1` and `gpt-4o-mini` queries when the sample was constructed. Always 1 in this dataset.

### sample_seed
Random seed used to construct the sample. Always 42 in this dataset.

### prompt_name
Prompt used for the original response and planned repetitions. Always `SimpleCapacityV8.1.1`.

### model_name
Model used for the original response and planned repetitions. Always `gpt-4o-mini`.
